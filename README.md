# 🧠 Machine Learning Laboratory

A comprehensive collection of **Jupyter Notebook** laboratory exercises designed to help students and beginners build a strong foundation in **Python**, **Data Analysis**, **Data Preprocessing**, and **Machine Learning** using industry-standard libraries such as **NumPy**, **pandas**, **Matplotlib**, **Seaborn**, and **Scikit-learn**.

This repository follows a structured, hands-on learning approach that begins with Python fundamentals and gradually progresses to implementing and evaluating machine learning models for both **classification** and **regression** tasks.

---

## 🚀 Project Highlights

* Beginner-friendly laboratory exercises
* Step-by-step implementation
* Real-world datasets
* Data preprocessing techniques
* Machine Learning with Scikit-learn
* Classification and Regression algorithms
* Model evaluation and performance analysis
* Well-documented Jupyter notebooks

---

# 📂 Repository Structure

| Notebook                         | Description                                                                                                                                                       |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Lab_1.ipynb**                  | Introduction to NumPy, matrix operations, array manipulation, broadcasting, and basic linear algebra.                                                             |
| **Lab_2.ipynb**                  | Python dictionaries and pandas DataFrame operations including data creation, filtering, sorting, indexing, and manipulation.                                      |
| **Lab_3.ipynb**                  | Titanic dataset preprocessing including missing value handling, categorical encoding, feature scaling, outlier detection, feature engineering, and visualization. |
| **Lab_4_Logistic_SVC_SVR.ipynb** | Machine Learning using Logistic Regression, Support Vector Classification (SVC), and Support Vector Regression (SVR) with complete model evaluation.              |
| **Lab_7.ipynb**                  | Linear Regression, Ridge Regression, and Lasso Regression using the California Housing dataset with performance comparison and visualization.                     |

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/subhash107k/Machine_Lab.git
```

Move into the project directory:

```bash
cd Machine_Lab
```

Install the required dependencies:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```
